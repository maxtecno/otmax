# OptimusMax Activation Tools

Herramientas de activación para Windows y Office basadas en proyectos open source.

## Créditos
- **MAS (Microsoft Activation Scripts)**: https://github.com/massgravel/Microsoft-Activation-Scripts
- **Get-Office-365**: https://github.com/NaeemBolchhi/Get-Office-365

## Uso
Ejecutar los scripts con PowerShell como Administrador.
